# 04 — открытые вопросы

Что неизвестно, кто должен ответить и как это изменит план.

## A. Требует владельца (ответы меняют план)

| № | Вопрос | Почему важно | Как ответ повлияет |
|---|---|---|---|
| A1 | Языковая стратегия: EN / RU / KY / всё сразу | Определяет URL-структуру, hreflang, контент-план | Если EN — оставляем текущий контент, добавляем RU-версию; если RU — переводим всё |
| A2 | Продаёте напрямую или через OTA | Разный тип сайта: воронка или витрина | Прямые продажи → формы, цены, оплата; OTA → карточки и ссылки на маркетплейсы |
| A3 | Публиковать цены или нет | 85% конкурентов публикуют | Если да — блок цен + `Offer` schema; если нет — калькулятор или форма запроса |
| A4 | Онлайн-оплата или заявка в мессенджер | Определяет набор плагинов и целей | Заявка → форма + WhatsApp; оплата → эквайринг + `Checkout` цели |
| A5 | Есть ли доступ к панелям (Вебмастер, GSC, Метрика) | Без них нет данных о трафике и позициях | Если есть — выгрузки за 3–6 месяцев; если нет — установка с нуля |
| A6 | Хостинг: где и какой | Определяет возможность кэша, HTTP/2, CDN | Shared → только плагины; VPS → полный тюнинг nginx |
| A7 | Есть ли разработчик | Разные ТЗ для разработчика и владельца | Разработчик → правки в теме и nginx; владелец → только через админку |
| A8 | Есть ли исходники фото | Влияет на возможность пережатия | Если исходников нет — пережатие только из текущих PNG с потерей качества |
| A9 | Есть ли отзывы клиентов | E-E-A-T и конверсия | Если есть — страница отзывов + `Review` schema; если нет — сбор отзывов |
| A10 | Есть ли юрлицо / ИП | Нужно для оферты и политики ПД | Есть → реквизиты в подвал; нет → работа как самозанятый |
| A11 | Сезонность | Контент-план и структура | Круглый год → зимние туры; май–октябрь → акцент на сезон |
| A12 | Бюджет и срок | Приоритет P0/P1 или поэтапно | Ограниченный бюджет → сначала P0; есть время → сразу P0+P1 |
| A13 | Нужен ли китайский рынок | Отдельный языковой кластер | Да → zh-версия, отдельный контент |
| A14 | Что уже пробовали в SEO | Избежать повторения ошибок | Если были покупки ссылок — проверить на фильтры |

## D. Что я не смог проверить и почему

| Что | Почему не проверено | Как обойти |
|---|---|---|
| PageSpeed Insights / Lighthouse | нет браузерного инструмента в этой сессии; API недоступен | запустить вручную на pagespeed.web.dev |
| Живая выдача Яндекс / Google | блокировки и CAPTCHA; обходить запрещено | попросить у владельца скриншот или выгрузку |
| Wordstat | требует авторизации | попросить выгрузку |
| Данные Wayback по домену | `archive.org` недоступен из моей сети | проверить вручную |
| Актуальные позиции | нужны панели | раздел B |
| Точная дата создания сайта | косвенно: sitemap от 30.07.2026 | уточнить у владельца |
| Скорость загрузки картинок у пользователей | мой канал даёт ~30 КБ/с на GET; это может быть ограничение канала, а не сервера | замерить PageSpeed Insights с реальным User-Agent |
