# 16 — юридические страницы и E-E-A-T

## Юридические страницы

| Страница | Статус | Что должна содержать |
|---|---|---|
| Политика конфиденциальности | отсутствует | какие данные собираются, зачем, как хранятся, права субъекта |
| Согласие на обработку ПД | отсутствует | чекбокс под формой, ссылка на политику |
| Cookie-уведомление | отсутствует | баннер + настройка |
| Публичная оферта | отсутствует | условия брони, оплаты, отмены, возврата |
| Реквизиты | отсутствуют | юрлицо / ИП, адрес, телефон, email |
| Условия отмены | отсутствуют | сроки и штрафы при отмене |
| Договор на оказание услуг | отсутствует | шаблон для бронирования |

## Что требуется по закону

| Требование | Основание | Статус |
|---|---|---|
| Согласие на обработку ПД | 152-ФЗ (РФ), аналоги в КР | не выполнено |
| Политика конфиденциальности | 152-ФЗ, GDPR для иностранных гостей | не выполнено |
| Cookie-баннер | GDPR / ePrivacy | не выполнено |
| Публичная оферта | гражданское законодательство | не выполнено |
| Реквизиты продавца | закон о защите прав потребителей | не выполнено |

## E-E-A-T — что есть и чего нет

| Сигнал | Статус |
|---|---|
| **Experience** (опыт) | нет: ни фото, ни историй, ни деталей маршрутов «из первых рук» |
| **Expertise** (экспертиза) | нет: нет авторов, гидов, сертификатов, биографий |
| **Authoritativeness** (авторитет) | нет: нет упоминаний, отзывов, ссылок, наград |
| **Trustworthiness** (доверие) | нет: нет реквизитов, политик, контактов, адреса |

## Что добавить для E-E-A-T

### 1. Страница «О нас» — усилить

Сейчас: 153 слова общих фраз. Нужно:

- Имя основателя или главного гида.
- Фото команды.
- История: когда начали, сколько туров провели.
- Сертификаты и обучение (если есть).
- Личное фото с лошадьми на маршруте.
- Цифры: количество гостей, стран, лет работы.

### 2. Страницы гидов

| Страница | Что внутри |
|---|---|
| `/guides/` | список гидов |
| `/guides/имя/` | фото, биография, опыт, языки, специализация, маршруты |

### 3. Отзывы

| Тип | Где разместить |
|---|---|
| Текстовые отзывы | на сайте, отдельная страница |
| Отзывы с фото | на сайте, с разрешения |
| Видео-отзывы | на сайте + YouTube |
| Отзывы на площадках | Яндекс Карты, 2GIS, Tripadvisor, Google |

Schema: `Review` + `AggregateRating` на странице отзывов.

### 4. Безопасность и снаряжение

| Раздел | Что описать |
|---|---|
| Подготовка лошадей | как выбираются, как обучаются |
| Инструктаж | что входит в брифинг |
| Снаряжение | седло, шлем, страховка |
| Медицина | аптечка, ближайшая больница |
| Связь | спутниковая связь, рации |
| Страховка | что покрывает |

### 5. Прозрачность бизнеса

| Элемент | Зачем |
|---|---|
| Реквизиты в футере | доверие |
| Политика конфиденциальности | закон |
| Условия бронирования | предсказуемость |
| Условия отмены | снятие возражений |
| Контакты (адрес, телефон) | доверие |

| Что | Где |
|---|---|

| Даты публикации и обновления | статьи блога |
