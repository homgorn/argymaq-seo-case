## Что внедрить

### 1. JSON-LD LocalBusiness / TouristBusiness

```json
{
  "@context": "https://schema.org",
  "@type": "TouristBusiness",
  "name": "ARGYMAQ KYRGYZSTAN",
  "url": "https://argymaq.kg/",
  "telephone": "+996 501 282 030",
  "priceRange": "$$",
  "address": {
    "@type": "PostalAddress",
    "streetAddress": "6/1 Masaliev St",
    "addressLocality": "Karakol",
    "addressRegion": "Issyk-Kul",
    "postalCode": "722200",
    "addressCountry": "KG"
  },
  "geo": { "@type": "GeoCoordinates", "latitude": 42.4907, "longitude": 78.3936 },
  "openingHours": "Mo-Su 08:00-20:00",
  "sameAs": ["https://www.instagram.com/...", "https://www.facebook.com/..."]
}
```

Координаты Каракола: 42.4907, 78.3936. Адрес — уточнить у владельца.

### 2. Страница «Контакты»

- Адрес с картой (2GIS embed или Яндекс Карты).
- Телефон кликабельный (`tel:`).
- WhatsApp и Telegram.
- Email.
- Мессенджеры и соцсети.
- Часы работы.
- Реквизиты (если есть юрлицо).
