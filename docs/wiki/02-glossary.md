# 02 — глоссарий

Термины и сокращения, используемые в отчётах по этому проекту.

## Обозначения источников

| Термин | Значение |
|---|---|
| **[измерено]** | проверено моим запросом к сайту; цифра приведена и воспроизводима |
| **[сообщено]** | взято из внешнего источника; указан URL и дата |
| **[выведено]** | логический вывод из измерений, не прямой факт |
| **[панель]** | данных нет без доступа к панели; требуется владелец |
| **[внедрение]** | действие по правке сайта, ещё не выполнено |
| **[человек]** | действие, которое нельзя автоматизировать |

## SEO-термины

| Термин | Значение |
|---|---|
| **TTFB** | Time To First Byte — время до первого байта ответа сервера. Норма — до 0,8 с, приемлемо — до 1,5 с, плохо — свыше 2 с. |
| **LCP** | Largest Contentful Paint — время отрисовки самого крупного элемента. Норма — до 2,5 с. |
| **INP** | Interaction to Next Paint — задержка реакции на действие. Норма — до 200 мс. |
| **CLS** | Cumulative Layout Shift — сдвиг вёрстки. Норма — до 0,1. |
| **Core Web Vitals** | три метрики выше; входят в сигналы ранжирования Google. |
| **Rich results** | расширенные сниппеты в выдаче: цена, рейтинг, FAQ, карточка товара. Требуют schema.org. |
| **schema.org / JSON-LD** | словарь структурированных данных и формат его передачи в `<script type="application/ld+json">`. |
| **hreflang** | атрибут, указывающий языковую и региональную версию страницы. |
| **canonical** | тег, указывающий канонический URL страницы, чтобы склеить дубли. |
| **E-E-A-T** | Experience, Expertise, Authoritativeness, Trustworthiness — сигналы качества контента для Google. |
| **GEO** | Generativ Engine Optimization — оптимизация под ответы нейросетей (ChatGPT, Perplexity, AI Overviews). |
| **AEO** | Answer Engine Optimization — то же по сути, оптимизация под поиск-ответы. |
| **OTA** | Online Travel Agency — маркетплейсы туров: GetYourGuide, KKday, Viator. |
| **DMC** | Destination Management Company — принимающая компания на направлении. |
| **ЧПУ** | человеко-понятный URL: без параметров, с ключом, короткий. |
| **ТЗ** | техническое задание на правки. |
| **Кластер** | группа запросов, объединённых общим интентом и целевой страницей. |
| **Интент** | намерение пользователя: коммерческое, информационное, брендовое, навигационное. |
| **Тургенев** | сервис проверки спамности текста (turgenev.ashmanov.com). |
| **Wordstat** | сервис Яндекса для оценки частотности запросов. |

## Сокращения в таблицах

| Сокращение | Значение |
|---|---|
| **зн.** | знаков (символов) |
| **слов** | слов в тексте страницы |
| **с** | секунд |
| **КБ / МБ** | килобайты / мегабайты |
| **alt** | альтернативный текст изображения |
| **LD** | наличие JSON-LD |
| **OG** | Open Graph |
| **H1 / H2 / H3** | заголовки первого, второго, третьего уровня |
