## Главный принцип

Клиент **не разбирается в SEO и вебе**. Значит:

- Никакого жаргона без перевода: «TTFB» → «как быстро открывается сайт».
- Каждая цифра объясняется: не «0 description», а «поисковик не знает, что показать в описании сайта — и берёт случайный текст».
- Приоритет объясняется деньгами: «сначала это — потому что без этого трафик уйдёт и не вернётся».
- Каждый блок заканчивается действием: «что это даёт вам» → «что делаем».

## Дизайн-система (по референсу Aceternity)

Референс `C:\susa ai\SCREENS SITE\ui.aceternity.com` — тёмный премиум, контент-первый.

| Токен | Значение | Откуда |
|---|---|---|
| Фон | `#000000` | `color.surface.base` |
| Поверхность | `#ffffff` | `color.surface.muted` |
| Текст | `#09090b` | `color.text.primary` |
| Текст 2 | `oklch(0.371 0 0)` | `color.text.secondary` |
| Бордер | `#e4e4e7` | `color.border.default` |
| Радиус | 7.6 / 9.6 / 10 / 20 px | `radius.*` |
| Анимация | 150 / 200 мс | `motion.duration.*` |
| Шрифт | системный стек | `font.family.stack` |
| Шкала | 11 / 14 / 16 / 18 / 20 / 24 / 30 / 48 | `font.size.*` |

**Но:** это тёмная тема. Для отчёта клиенту нужна **светлая** — тёмный фон в 12 экранов цифр утомляет. Поэтому:

- Базовая тема: светлая (белый фон, тёмный текст).
- Тёмная — опционально (переключатель).
- Акцент: один цвет для «проблема» (красный), один для «решение» (зелёный), один для бренда.

## Стек

| Слой | Выбор | Почему |
|---|---|---|
| Статика | **Astro 7** (static) | 0 JS по умолчанию, быстрый, деплой в Pages |
| Стили | **Tailwind v4** через `@tailwindcss/vite` | по регламенту скилла |
| Графики | **Chart.js** (tree-shakeable) | клиенту нужны графики, а не 300 КБ библиотеки |
| Анимации | CSS + немного GSAP | 150–200 мс, без «мультиков» |
| Данные | JSON в `src/data/` | build-time, никакой БД |
| Форма | `mailto:` + WhatsApp/Telegram ссылка | без бэкенда, статично |
| Деплой | GitHub Pages | по требованию владельца |

## Продвижение под нейронки (GEO/AEO) — новое направление

| Что | Как измеряем | Как показываем клиенту |
|---|---|---|
| Упоминания в ChatGPT | % ответов, где назван бренд | «Из 50 вопросов о конных турах в Караколе ChatGPT называет вас в 3» |
| Упоминания в Perplexity | то же | «Самая цитируемая площадка — Reddit, вас там нет» |
| Google AI Overviews | % показов | — |
| Доля голоса (share of voice) | упоминания / все упоминания | «Вас 3%, конкурента — 44%» |
| Тональность | позитив / нейтрал / негатив | «Вас описывают как "одного из", а конкурента — как "лучший"» |
| Источники цитирования | какие сайты | «Нужно попасть в 5 сайтов, которые ИИ цитирует» |
| Переходы из ИИ | визиты из ChatGPT/Perplexity | «12 переходов, 3 заявки» |

**Как это делается:**
1. Список из 50–150 вопросов покупателя.
2. Прогон раз в неделю по ChatGPT, Perplexity, Google AI Overviews.
3. Фиксация: упомянут / не упомянут, на каком месте, что сказано, какие источники.
4. Отчёт: тренд, а не снимок (ИИ даёт разные ответы на один вопрос).
5. План: какие страницы создать, где разместиться, какую разметку добавить.

## Локальное продвижение: карты

| Площадка | Что делаем | Метрика | Как показываем |
|---|---|---|---|
| **Яндекс Карты** | карточка, категории, 20+ фото, услуги с ценами, отзывы, ответы, посты раз в 3–4 дня | просмотры, клики по телефону, маршруты | «Было: карточки нет. Стало: 340 просмотров, 28 звонков» |
| **2GIS** | карточка, рубрики, прайс-лист, фото | просмотры, звонки | «В 2GIS вас не было — теперь вы в топ-3 по "конные туры Каракол"» |
| **Google Business Profile** | профиль, категории, фото, отзывы, посты | показы в Maps, клики | «Туристы из-за рубежа находят вас в Google Maps» |
| **NAP-консистентность** | Name/Address/Phone одинаково везде | проверка | «Телефон на сайте, в 2GIS и в Яндексе был разный — исправили» |

**Что важно для клиента:**
- Карточка с 90%+ заполненностью получает буст в ранжировании.
- Рейтинг ниже 4.3 — красный флаг. Выше 4.7 при 50+ отзывах — преимущество.
- 2GIS: не отвечаете на отзывы 5 дней — штраф.
- 2GIS: прайс-лист прямо в карточке снижает нецелевые звонки.

## Границы

- Не выдумываем цифры «стало»: если правки не внедрены — пишем «в работе».
- Не обещаем позиции и сроки.
- Не копируем чужой контент.
- Цены — из открытых источников, с датой замера.
- Реальные кейсы конкурентов не используем как свои.
