# AGENTS.md — правила работы в этом репозитории

Проект: репозиторий «argymaq.kg — аудит сайта и план внедрения».

Единственный объект этого репозитория — сайт argymaq.kg и его аудит.
Личное портфолио разработчика и агентские страницы здесь не публикуются;
они живут в репозитории homgorn/homgorn.github.io.

Всё, что делается в этом чате/репозитории, относится к argymaq.kg.

## Стек

```
Astro 5 (static, без adapter)
Tailwind v4 через @tailwindcss/vite  — НЕ `astro add tailwind`
Chart.js для графиков
TypeScript
Деплой: GitHub Pages (legacy, /docs, ветка main)
```

## Команды

```bash
cd site
npm run dev      # локальный сервер
npm run build    # сборка в dist/
npm run preview  # предпросмотр сборки
npm run check    # astro check (типы)
```

Публікация = копия `site/dist` → `docs/` (Pages раздаёт из `/docs`).
После этого `git push origin main`.

## Жёсткие правила

1. **Удаление запрещено** без двойного подтверждения человека. Это касается файлов, данных, кейсов, изображений. Если уверен, что файл мусорный — сначала спроси.
2. **Не выдумывать цифры.** Каждая метрика «стало» должна быть либо измерена, либо помечена «в работе / цель».
3. **Аудитория — владелец сайта, а не SEO-специалист.** Любой термин переводится на человеческий язык.
4. **Не копировать чужой контент** — ни тексты, ни изображения.
5. **Источники — с URL и датой.** Цены меняются, дата обязательна.
6. **Static first.** Никакого adapter/SSR, пока статика не собирается.
7. **Не редактировать package.json руками** — только `npm i` / `npx astro add`.
8. **Сборка = гейт.** `npm run build` exit 0 до слов «готово».
9. **Ничего про агентство и продажи.** Этот сайт — отчёт о сайте argymaq.kg, не предложение услуг.

- [ ] Изображения с alt
